# Agribloom Farms Static Website

This folder contains the complete website as plain HTML, CSS, and a small vanilla JavaScript file. It does not use React and has no build step.

## Pages

- `index.html` — Home
- `products.html` — Products
- `farming-practices.html` — Farming Practices
- `operations.html` — Our Operations
- `buyers-exporters.html` — For Buyers and Exporters
- `investors.html` — Investors
- `gallery.html` — Gallery and Blog
- `careers.html` — Careers
- `contact.html` — Contact Us

All HTML, CSS, JavaScript, logo, and image files are in this single folder. Upload the complete folder contents to the root of a GitHub repository and enable GitHub Pages from the main branch.
